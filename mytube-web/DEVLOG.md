# MyTube Web — ডেভলগ

## স্থায়ী নিয়ম (ইউজার-নির্দেশ, v0.9 থেকে)
- **অ্যাপের UI-তে কোনো ইমোজি নয়** — প্লেইন টেক্সট/আইকন
- **অ্যাপের UI-তে কোনো বাংলা-লেখা নয়** — সব ইংরেজি

**কনসেপ্ট:** MyTube (Vancad-মড) প্রজেক্টের উত্তরসূরি। ভিত্তি বদলে নতুন অ্যাপ:
WebView-ভিত্তিক ইউটিউব (ডাইরেক ওয়েব) + অ্যাড-ব্লক + ব্যাকগ্রাউন্ড প্লে + (পরে) ফাস্ট ডাউনলোড।
পুরনো প্রজেক্টের যাবতীয় শিক্ষা ও কোড-সম্পদ PATCH_NOTES.md ও DownloadHub.java-তে সংরক্ষিত।

## আর্কিটেকচার
- `MainActivity` — WebView + JS-ব্রিজ (`MTApp`), ইউটিউব-লিংক হ্যান্ডলিং, http→https, অ্যাপ-স্কিম ব্লক
- `AdBlock` — shouldInterceptRequest-এ হোস্ট-সাফিক্স + পাথ-ব্লক (doubleclick, googlesyndication, /api/stats/ads, /pagead/, /ptracking…)
- `BgService` — mediaPlayback ফোরগ্রাউন্ড-সার্ভিস; নোটিফের বাটন থেকে JS টগল
- `assets/inject.js` — (১) document.hidden=false ট্রিক → ওয়েব-প্লেয়ার নিজেকে পজ করতে পারে না = ব্যাকগ্রাউন্ড প্লে,
  (২) কসমেটিক অ্যাড-হাইড CSS, (৩) ভিডিও play/pause → সার্ভিস চালু/বন্ধ, (৪) ৫০০ms স্কিপ-অ্যাড ক্লিকার
- `build.sh` — সেল্ফ-কন্টেইন্ড বিল্ডার: aapt2+javac+d8+uber-signer; টুলগুলো /tmp-তে অটো-ডাউনলোড
  (platform-36_r01 ✓, build-tools r36 ✗→r34 ফলব্যাক, r8 3.3.75)। বিল্ড-সময় ~৭ সেকেন্ড।
- সাইনিং-কী: patchwork/webtube.p12 (mytube2026) — v0.1 থেকে এই এক কী; একই কীতে সাইন করলে পুরনো ভার্সনের উপরেই আপডেট হবে।

### আসল অভিযোগের সমাধান: "স্ক্যান" কেন?

ব্যবহারকারী ঠিকই ধরেছেন — ভিডিও-লিংকে "Searching for media..." দেখানো
বেমানান। তিনটি পরিবর্তন:

1. **`directExt()`** — পেস্ট করা লিংকটাই যদি ভিডিও-ফাইল হয় (`....mp4`,
   `.m4a`, `.webm` …), কোনো এক্সট্র্যাকশন/স্ক্যানই হয় না; সাথে সাথে
   এক সারি আসে, লেখা **"Preparing download..."**।
2. **`parseGeneric()`** — যেকোনো সাইটের জন্য: `og:video`,
   `og:video:secure_url`, `og:video:url`, `twitter:player:stream`,
   JSON-LD `contentUrl`, `<video src>`, `<source src>`। সাইটভিত্তিক কোড
   ছাড়াই "যেকোনো প্ল্যাটফর্ম" অনেকটাই সত্যি হলো।
3. **`canHandle()`** এখন ইউটিউব বাদে **সব** http(s) লিংকে true — ফলে
   এক্সট্র্যাকশন আগে চলে, পেজ-স্ক্যান শুধু ফলব্যাক। শিটে লেখা এখন
   **"Resolving link..."** (স্ক্যান নয়)।

ইউটিউবের পথ অটুট — `canHandle()` ওখানে false।
